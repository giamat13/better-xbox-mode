# Xbox Mode 1.0.0

מצב קונסולה למסך מלא ל-Windows, שמופעל כולו עם בקר משחק. זו הגרסה הראשונה.

## תכונות חדשות

- מסך בית, ספרייה של אפליקציות (כולל אפליקציות מ-Microsoft Store) עם חיפוש.
- מעבר בין אפליקציות פתוחות בכפתור Guide.
- לחיצה ארוכה על Guide פותחת הגדרות מהירות: עוצמת קול, בהירות, Wi-Fi, Bluetooth, צילום מסך, נעילה, שינה, הפעלה מחדש וכיבוי.
- שליטה בעכבר בתוך חלונות רגילים: מקל שמאל מזיז את הסמן, A ו-X לחיצה, מקל ימין לגלילה.
- מקלדת על המסך בעברית, באנגלית ובסמלים, עם הצעות מילים, קיצורי מקלדת ואמוג'י.
- לשונית Places: אתרים מועדפים, תיקיות וקבצים אחרונים.
- הגדלת המסך כולו עם LT ו-RT.
- מצב משחק לכל תוכנה ולכל אתר: משחק שקורא את הבקר בעצמו נשאר עם הבקר.
- הרצה כמנהל (אופציונלי, בהגדרות), וסימון סוללת הבקר עם התראה כשהיא חלשה.
- תוסף Chrome שמוסיף שליטה בבקר ל-YouTube. התוסף לא כלול בהתקנה: טוענים אותו מתיקיית `extension` במאגר.

## נבדק ידנית

הרצה של התוכנה עם בקר XInput אמיתי ב-Windows לפני השחרור.

## דרישות

- Windows 10 או 11.
- Python 3.10 ומעלה ב-PATH, בשם `python`. ההתקנה לא כוללת את Python.
- בקר XInput (בקרי Xbox ורוב הבקרים התואמים).
- ההתקנה לא חתומה דיגיטלית: Windows SmartScreen עלול להציג אזהרה. לוחצים על "מידע נוסף" ואז "הפעל בכל זאת".

## קבצים

- `xbox-mode-1.0.0-setup.exe` - מתקין למשתמש הנוכחי, בלי הרשאות מנהל. ההתקנה מוסיפה את התוכנה להפעלה עם Windows; הסרת ההתקנה מוחקת את ההפעלה האוטומטית.
- `xbox-mode-1.0.0-portable.exe` - גרסה נייחת, בלי התקנה. היא לא מופעלת עם Windows.
